# ingrid_core

Rust crossword-fill library (Ingrid) plus `zkw`, the generator for the German "Zuordnungs-Kreuzwort"
puzzle series.

- Making, checking or publishing puzzles: follow `PUZZLE-WORKFLOW.md`.
- Design decisions behind the series: `PLAN.md`.
- Build: `cargo build --release`; test: `cargo test --release`.
